# mangen

Утилита командной строки для генерации манифеста каталога: для каждого файла
выводится его путь относительно каталога и хэш-сумма.

Написана под Linux (POSIX: `dirent.h`, `stat`/`lstat`).

## Сборка

Нужны CMake ≥ 3.12 и компилятор C.

```sh
cmake -S . -B build
cmake --build build
```

Бинарник: `build/mangen`.

## Использование

```
mangen [DIR_PATH] [OPTIONS]
```

Если `DIR_PATH` не указан, используется текущий каталог.

| Опция | Описание |
|---|---|
| `-h`, `--help` | справка |
| `-v`, `--version` | версия, автор и git commit hash сборки |
| `-e`, `--exclude NAME` | исключить файлы и каталоги с именем `NAME`; можно указывать несколько раз |

`NAME` сравнивается с именем целиком и может быть regex шаблоном.  
**Шаблоны брать в кавычки, чтобы их не раскрыл shell!**

```sh
$ mangen example -e dir_2 -e '*.png'
file_1.txt : 435657D4
file_3.c : 7FDA81B0
dir_1/file_4 : 4A327460
dir_1/file_5.sh : 3D64306B
```

Манифест выводится в stdout, ошибки (недоступные файлы и каталоги) — в stderr;
обработка остальных файлов при этом продолжается.

## Структура

```
main.c    разбор аргументов -> обход каталога -> вывод манифеста
cli.c     разбор аргументов командной строки
walker.c  итеративный обход в ширину
logic.c   хэширование файлов (чтение блоками), список пар путь–хэш,
          сопоставление с шаблонами -e
hash.c    алгоритм хэширования
darray.h  динамические массивы
```

## Хэширование

Используется CRC-32 (IEEE 802.3). Хэш выводится 8 hex-символами.

Интерфейс в `hash.h` от алгоритма не зависит (`hash_init` / `hash_update` /
`hash_final`), а сам хэш — это массив байт длиной до 32. Поэтому алгоритм можно
заменить вплоть до 256-битного (например, SHA-256), переписав только `hash.c`.

## Тесты

```sh
ctest --test-dir build --output-on-failure
```

- `tests/unit/` — unit-тесты модулей на C
- `tests/e2e/` — end-to-end тесты: CMake-скрипты, запускающие собранный `mangen`
  на созданных деревьях каталогов
